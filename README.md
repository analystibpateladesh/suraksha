# Suraksha : A Women Safety App 🛡️

One press sends live location, auto-calls trusted contacts & 
alerts nearby helpers. Works without internet via SMS.

## Tech Stack
- **Frontend:** Android (Java/Kotlin) — Android Studio
- **Backend:** Firebase (Firestore, Auth, FCM, Hosting)
- **Maps:** Google Maps SDK
- **Offline SMS:** Android SmsManager API

## Features
- 3-second SOS hold trigger
- Live GPS location sharing
- Offline SMS (no internet needed)
- Nearby helper alerts via FCM
- Fake call feature
- Silent triggers (volume button / shake)
